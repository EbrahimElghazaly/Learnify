## 🌟 Overview | نظرة عامة

### 🇬🇧 English

**Learnify** is a comprehensive personal learning management system built specifically for aspiring **Full Stack .NET** developers. It tracks your daily progress through a structured **180-day curriculum**, helping you stay motivated and organized on your learning journey.

The platform is designed to be:

| Feature | Description |
|---------|-------------|
| **💾 100% Offline** | No internet connection required after initial load |
| **📦 Self-contained** | Everything runs in your browser with Local Storage |
| **📈 Progressive** | Starts as a frontend app, evolves into a Full Stack application |
| **🎨 Beautiful UI** | Neon Galaxy theme with glassmorphism effects |
| **📱 Responsive** | Works perfectly on all devices |

### 🇸🇦 العربية

**ليرنيفاي** هي نظام إدارة تعلم شخصي شامل مبني خصيصاً للمطورين الطموحين في مجال **Full Stack .NET**. يتتبع تقدمك اليومي من خلال **منهج دراسي منظم لمدة 180 يوم**، مما يساعدك على البقاء متحفزاً ومنظماً في رحلة التعلم الخاصة بك.

المنصة مصممة لتكون:

| الميزة | الوصف |
|--------|-------|
| **💾 تعمل دون اتصال 100%** | لا تحتاج اتصال بالإنترنت بعد التحميل الأولي |
| **📦 مكتفية ذاتياً** | كل شيء يعمل في المتصفح باستخدام Local Storage |
| **📈 تطورية** | تبدأ كتطبيق واجهة أمامية، وتتطور إلى تطبيق Full Stack |
| **🎨 واجهة جميلة** | سمة نيون غالاكسي مع تأثيرات الزجاج الشفاف |
| **📱 متجاوبة** | تعمل بشكل مثالي على جميع الأجهزة |
